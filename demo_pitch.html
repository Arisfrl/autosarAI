What Makes This Different

Not generic chatbot output. This is a controlled model-driven pipeline.

  1. Uses local AUTOSAR references (grounded generation).
  2. Forces schema sections: system, ecus, services, signals, safety.
  3. Compiles to ARXML for downstream model workflows.
  4. Runs safety-focused checks before handoff.

Result: faster drafts, fewer manual formatting errors, better traceability.

Core Features (README)

  1. RAG-backed generation from local AUTOSAR references.
  2. Simplified AUTOSAR YAML output for architecture and services.
  3. Compile path from YAML to ARXML-like artifact.
  4. ISO 26262/ASIL-oriented safety checklist.
  5. Demo prompt builder for CAN to SOME/IP scenarios.

Setup and Tenant Isolation

  1. Pull model: ollama pull llama3.1
  2. Create venv and install requirements.
  3. Launch app with Streamlit and login by tenant.
  4. Tenant-scoped Chroma storage: chroma_db/<tenant>/
  5. Tenant-scoped audit log: audit/<tenant>_audit.jsonl
